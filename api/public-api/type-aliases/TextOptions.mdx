## Type Alias: TextOptions

> **TextOptions** = [`RawTextOptions`](/api/public-api/type-aliases/RawTextOptions) & `object`

## Type declaration

### formatting?

> `optional` **formatting**: [`FormatRange`](/api/public-api/type-aliases/FormatRange)[]

A list of FormatRange specifications which defines text style for an
arbitrary substring within the text

#### See

 - [FormatRange](/api/public-api/type-aliases/FormatRange)
 - makeFormatting

#### Example

```ts
// Make the exclamation mark italic:
{ text: 'Hello!', formatting: [makeFormatting({italic: true, startIndex: 5, length: 1})] }
```
