---
title: "Conversions API"
---

Send server-to-server event data to Reddit for more accurate tracking, especially in cookie-restricted environments.

## Considerations

-   CAPI supports a variety of sources, including web, app, and offline events.
-   There’s a rate limit of 1,000 requests/second, 10,000 events/second, and 1,000 events/request.
-   We recommend sending conversions via CAPI as close to real-time as possible, but events must be sent within seven days after they occur.
-   We require [event deduplication](https://business.reddithelp.com/s/article/event-deduplication) if you use the [Reddit Pixel](https://business.reddithelp.com/s/article/reddit-pixel) and [Conversions API](https://ads-api.reddit.com/docs/v3/api/post-conversion-events) together (which we recommend for best performance). The event with more event metadata and match keys will be prioritized. Deduplication is not required when the event is only sent through one integration type. Learn more about [event deduplication](https://business.reddithelp.com/s/article/event-deduplication).
-   Some [match keys (unique event and user identifiers)](https://business.reddithelp.com/s/article/about-match-keys) are required for each conversion event to ensure accurate matching and attribution. We recommend sending as many identifiers as possible to help improve attribution accuracy and fuel performance.

    <Tip>

    Use the [Data Deletion API](/ads-api/guides/programs/data-deletion/delete-user-data) to request deletion of ads-related match key data.

    </Tip>

-   Your use of CAPI is subject to the agreements in the [Ads API](https://www.reddithelp.com/en/categories/advertising/policy-guidelines/reddit-ads-api-terms) and [Reddit Business Tool](https://business.reddithelp.com/s/article/Reddit-Business-Tool-Terms) terms.
